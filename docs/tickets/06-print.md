# 06 — 使用者可以從 Windows 列印文件

Epic：列印。User Story：使用者恢復這台多功能機的列印能力。
Blocked by：無程式相依，排程在優先掃描成果之後。Status：尚未開始。

## 交付與流程

Windows 列印佇列 → 已驗證的光柵／列印格式 → MI_01 → 實體紙張。

## 驗收

- 從一手資料與實機結果確認真正的列印語言，不能預設為 PCL、PostScript 或 IPP。
- 先以小型測試頁驗證紙張大小、方向與內容，再完成佇列安裝及常用設定。
- 空文件、無效尺寸、未連接、缺紙及傳輸失敗有明確結果。取消工作不污染下一個工作。
- 與掃描同時操作時正確回報或處理裝置忙碌，不使任一介面失去驅動。
- 驗證從一般 Windows 軟體列印、取消、重印、重開機後列印與解除安裝。

## 測試

以實際列印資料和實體紙張核對。列印會耗用紙張及碳粉，測試前選擇小範圍頁面並告知使用者。
