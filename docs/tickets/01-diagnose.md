# 01 — 使用者可以確認連線與缺少的驅動

Epic：硬體連線。User Story：使用者知道掃描器為何尚未就緒。
Blocked by：無。Status：驗證中。

## 交付與流程

CLI → Windows 裝置查詢 → 精確 ID 分類 → 驅動狀態與下一步提示。

## 驗收

- 唯讀辨識 0924:4265 的父裝置、MI_00、MI_01，不把相似 ID 或列印介面當成掃描就緒。
- 無參數顯示說明，空字串參數與未知參數回傳 64。零裝置或多個掃描目標回傳 2，不自動選第一個。
- 區分問題碼 28、其他裝置錯誤、未啟動、其他驅動與 WinUSB 已啟動。
- 列舉失敗、拒絕存取或拔線造成查詢失敗，由 CLI 回報原始錯誤及結束碼 1。
- 清單大小在查詢間變化時有限次重試，不無限迴圈。
- 說明與輸出清楚標示尚不能掃描，不記錄序號。實機輸出須與系統查詢一致。
